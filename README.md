# Arcanum UAP hotfixes

Unofficial hotfixes for the [Unofficial Arcanum Patch](https://terra-arcanum.com/drog/uap.html)

While UAP does a great job of fixing an enourmous amount of various Arcanum bugs, after countless of walkthroughs some issues are still discovered.  
This hotfix intends to address them in games with UAP 2.0.2 installed.

See [changelog](./CHANGELOG.md) for the full list of fixes.

If you only interested in reading the restored dialogue, check [spoilers](./SPOILERS.md).

## Installation

- Grab `Arcanum.PATCH8` from the [Releases](https://github.com/Dergash/arcanum-uap-hotfixes/releases) Assets section and put it into your `Arcanum\modules` folder
- Grab `Arcanum8.dat` from the [Releases](https://github.com/Dergash/arcanum-uap-hotfixes/releases) Assets section and put it into your `Arcanum` root folder

## Compatibility

These patches are specifically for UAP 2.0.2

I haven't played with Grand Fix for many years and do not play with Multiverse Edition at all, so at this moment can't confirm if these fixes are compatible with them.
